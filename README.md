# MAFFT-sparsecore benchmark

Benchmark results and datasets associated with:

> Yamada KD, Tomii K, Katoh K, Application of the MAFFT sequence alignment program to large data - reexamination of the usefulness of chained guide trees, Bioinformatics, 2016.

## Website

The complete benchmark tables are published at:

<https://caramelazuki.github.io/MAFFT-sparsecore/>

## Datasets

- [HomFam](https://github.com/caramelazuki/MAFFT-sparsecore/releases/download/datasets-v1/homfam.tgz)
- [OXFam](https://github.com/caramelazuki/MAFFT-sparsecore/releases/download/datasets-v1/oxfam.tgz)

The archived files are distributed through the [`datasets-v1`](https://github.com/caramelazuki/MAFFT-sparsecore/releases/tag/datasets-v1) release.

BAliBASE and PREFAB are not redistributed in this repository. Please obtain them from their original providers:

- [BAliBASE](https://bigest-icube.fr/balibase/)
- [PREFAB](https://www.drive5.com/bench/)
